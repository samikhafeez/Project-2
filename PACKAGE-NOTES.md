# Repository contents and local assets

This project is part of a prepared local Git repository. Code, notebooks, saved evaluation reports, figures and documentation are tracked. The local working tree also contains the original datasets, trained model files and media where those existed in the source project.

Datasets, model weights, face encodings, media, session logs and duplicate archives are excluded by `.gitignore`. They remain available locally but will not be included in a normal Git push. A fresh clone requires compatible data and checkpoints at the paths documented in this project's README. Training may generate new artifacts; some historical notebooks also require their original hard-coded paths to be adapted.

Source code and saved notebook results are preserved. Repository preparation did not run training or validate model inference. Existing runtime limitations and recorded evaluation caveats still apply.

The repository contains contribution guidance, a change log and static validation. No open-source licence has been selected or added; dataset and third-party file terms are not changed by packaging.
